- inserido item 4: limite de envio de fotos

-------------------------------------------------

1. As fotos dos imoveis devem ser armazenadas em pasta apropriada, indexadas de maneira apropriada para realizar a separacao logica das fotos entre os proprietarios e imoveis.
2. As fotos, na página de edição da propriedade, devem possuir uma lógica de seleção para poderem ser apagadas de maneira mais intuitiva, como em sites de fotos. A seleção para exclusão é feita clicando na própria foto. Uma vez selecionado um conjunto de fotos, a ação de exclusão vale para esse conjunto pré-selecionado.
3. Deverá ser possível selecionar qualquer uma das fotos para ser a foto principal de capa, mostrada no resultado de pesquisa.
4. Na página de fotos, o navegador soma os arquivos antes de enviar. Se uma foto passar de 16 MB, se forem mais de 40, ou se o total passar de 128 MB, o envio não sai e a página mostra o motivo. Se um envio grande ainda chegar, o sistema responde que passou do limite, sem quebrar a sessão.
